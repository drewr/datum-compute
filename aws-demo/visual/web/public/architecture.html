Architecture

← back to the live map

Instances in AWS regions join one private Datum network over iroh. A Datum compute instance on that network draws them. The count below is the live fleet size.

  • Join. Each instance runs the Datum Connect daemon as a service account, enrols as a connector and joins aws-test-net through one gateway in us-east-1 (QUIC, relayed when it cannot go direct).
  • Hub and spoke. Members only reach peers on the same gateway, so traffic between two instances goes through it. Latencies on the map are measured over this path.
  • Push, not pull. The viewer cannot route to members' addresses, so each member measures its peers and POSTs a report to the viewer on the VPC.
  • Management. No SSH and no inbound ports on the instances: access is AWS Systems Manager; the service-account key lives in SSM Parameter Store and is deleted from the instance after enrolment.
